# As-Is: 체크아웃 화면 기획서 (예시, 가상 데이터)

## 화면: 주문 확인

- 상단에 파란색 "주문 확인" 타이틀 텍스트
- 상품 리스트: 각 항목에 상품명, 수량, 가격 표시. 항목 간 회색 구분선.
- 쿠폰 입력란: 텍스트 인풋 + 옆에 회색 "적용" 버튼
- 배송지 카드: 흰 배경, 얇은 테두리, 우측 상단에 "변경" 텍스트 링크
- 하단 고정 영역: 좌측에 총 금액 텍스트(크게, 굵게), 우측에 파란색 "결제하기" 버튼
- 결제 실패 시: 화면 상단에 빨간 배경 경고 배너 표시, "다시 시도" 버튼(빨간 테두리, 흰 배경)

## 화면: 쿠폰함

- 쿠폰 리스트: 카드 형태, 각 카드에 쿠폰명 + 만료일 + "사용하기" 버튼(파란색, 결제하기 버튼과 동일해 보이나 스타일 시트가 다름)
- 쿠폰 없음: "보유한 쿠폰이 없습니다" 안내 텍스트만 표시 (별도 컴포넌트 없음)

## 화면: 배송지 관리

- 배송지 리스트: 각 항목 카드형, 우측에 "수정" / "삭제" 텍스트 링크 두 개 나란히 배치
- 새 배송지 추가: 하단에 "+ 배송지 추가" 버튼 (주문 확인 화면의 "적용" 버튼과 색이 같지만 다른 팀이 만들어 padding이 다름)

## 공통 이슈 (기획자 메모)

- "적용", "사용하기", "결제하기", "+ 배송지 추가" 버튼이 화면마다 색은 비슷한데 크기/여백이 조금씩 다름
- "변경", "수정", "삭제" 링크가 버튼처럼 보이는 곳도 있고 텍스트 링크로만 보이는 곳도 있음
- 에러/경고 표시 방식이 화면마다 다름 (배너 vs 버튼 테두리만 변경)
