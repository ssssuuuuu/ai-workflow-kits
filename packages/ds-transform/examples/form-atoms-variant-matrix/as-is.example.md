# As-Is: 권한 설정 화면 기획서 (예시, 가상 데이터)

## 화면: 팀원 권한 설정

- 권한 항목마다 네모 체크박스: "전체 선택" 체크박스는 일부만 선택됐을 때 가로줄(部分選択) 표시가 필요하다고 코멘트만 있음
- 체크박스에 마우스 올리면 배경색이 살짝 변함(정확한 색상 미지정)
- 접근 레벨 선택: 동그란 라디오 버튼 3개(읽기/쓰기/관리자), 하나만 선택 가능
- 라디오 버튼도 비활성화되는 경우가 있음(권한 없는 사용자에게는 회색 처리) — 정확한 비활성 스타일은 "버튼 컴포넌트 참고"라고만 적혀 있음
- 하단 버튼 2개: 파란 배경 "저장" 버튼(크게), 테두리만 있는 "취소" 버튼(같은 크기)
- 화면이 좁아지면(모바일) 버튼이 작아짐 — 정확한 크기 단계는 명시 안 됨
- 각 체크박스/라디오 옆에 항목명 텍스트와, 그 아래 작은 회색 설명 문구("이 권한은 결제 정보 접근을 포함합니다" 등)
- 필수 동의 체크박스에는 항목명 옆에 빨간 별표, 설명 문구가 빨간색으로 바뀌는 에러 케이스도 있음(자세한 조건은 없음)

## 기획자 메모

- 체크박스/라디오의 hover, disabled 색상이 화면마다 다르게 그려져 있어 통일 필요
- 저장/취소 버튼의 크기 단계(데스크톱/모바일)가 명확히 정의된 적이 없음
- 설명 문구가 에러로 바뀌는 조건과 색상이 기획서마다 다름
