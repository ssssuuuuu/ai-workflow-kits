# As-Is: 대시보드 차트 라벨 기획 메모 (예시, 가상 데이터)

## 화면: 매출 대시보드 - 막대 그래프

- 막대 위에 숫자 표시: 보통은 회색, 이번 달 막대만 진하게(굵게) 강조
- 막대 아래 항목명: 작은 글씨, 가운데 정렬
- 여러 개 막대를 묶어 보여줄 때는 항목명들을 오른쪽 정렬로 바꿔서 보여준 화면도 있고, 왼쪽 정렬로 보여준 화면도 있음 (통일 안 됨)
- 범례: 화면이 좁을 때는 한 줄로 못 들어가서 두 줄로 줄바꿈되는데, 디자인 시안에는 반영 안 되어 있어서 개발자가 임의로 처리 중
- 강조가 필요한 값(예: 전월 대비 하락)은 빨간색 숫자로 별도 표시, 상승은 별도 색 언급 없음(기획 누락)

## 기획자 메모

- 라벨/값 텍스트의 크기 종류가 화면마다 제각각이라 몇 종류가 필요한지 정리 필요
- 범례 줄바꿈 규칙이 기획서에 없어 개발/QA 단계에서 매번 재논의됨
