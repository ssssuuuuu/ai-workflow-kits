# As-Is: 알림/할일 목록 화면 기획 메모 (예시, 가상 데이터)

## 화면: 할일 목록

- 목록으로 항목이 쭉 나열됨. 항목마다 생김새가 조금씩 다름:
  - 어떤 항목은 왼쪽에 체크박스가 있고, 어떤 항목은 없음
  - 제목은 항상 있음
  - 제목 옆/아래에 "3일 전", "홍길동" 같은 부가 정보가 회색으로 붙기도 함
  - 오른쪽에 하트(즐겨찾기) 아이콘이 있는 항목도 있음
  - "자세히", "수정" 같은 밑줄 텍스트 링크가 항목마다 1~2개 붙음
- 어떤 화면(피드형)에서는 이 부가정보/링크가 항목 오른쪽에 정렬되고, 다른 화면(설정형)에서는 왼쪽에 정렬됨
- 디자이너 메모: "항목 안에 들어가는 요소(제목/부가정보/라벨/체크박스/아이콘)는 같은데, 어디에 배치하냐만 화면마다 달라요. 매번 새로 그리는 중"

## 기획자 메모

- 항목 하나가 제목/설명/메타/라벨/체크박스/아이콘의 조합인데, 조합·배치 규칙이 문서화돼 있지 않아 개발자가 화면마다 재구현
- "같은 항목의 좌/우 정렬 버전"을 별도 컴포넌트로 볼지, 한 컴포넌트의 변형으로 볼지 불명확
