# As-Is: 주택금융 포털 홈 화면 기획 메모 (예시, 가상 데이터)

> 모든 브랜드·상품명은 가상입니다. 실제 기관/상품과 무관합니다.

## 화면: "온누리 인터넷 금융서비스" 홈

### 상단 헤더
- 왼쪽에 로고: 심볼 + "온누리주택금융 / 인터넷 금융서비스" 워드마크
- 로고 위쪽 줄에 작은 텍스트 링크 3개: "모기지론 신청방법", "주택연금 신청방법", "보증이행 신청방법" (대괄호로 감싼 스타일)
- 오른쪽 위에 버튼 2개: "로그인", "인증·보안" (테두리만 있는 버튼)
- 그 아래 줄에 메뉴 4개: "My 온누리", "신청", "간편 서류제출", "고객서비스"
- 오른쪽 끝에 아이콘 3개: 검색 돋보기, 브랜드 배지, 햄버거(≡)

### 히어로
- 큰 문구: "국민과 함께 성장하는 **글로벌 주택금융 리더**" (뒷부분만 굵게/컬러)

### 메인 카드 (좌우로 넘기는 슬라이드, 3장)
- 카드1: "든든 모기지론" / "0.1%p 더 저렴한 금리" / "최대" / **"주택가격 6억원"** (파란 큰 숫자) / 집+사람 일러스트
- 카드2: "새싹 전세자금대출" / "우리 가족의 소중한 보금자리" / "최대" / **"대출한도 3.6억원"** / 사람 일러스트
- 카드3: "AI 맞춤추천 플랫폼" / "AI 모기지 추천서비스" / **"상품구성추천"**, **"AI금리체험"** (파란 링크 2줄, 앞 두 카드의 '최대+숫자'와 구조가 다름) / AI 일러스트
- 아래에 슬라이드 점 표시(●○○)와 재생(▶) 버튼

### 퀵링크 바 (하단 흰 박스, 아이콘+글자 8개)
- 기준금리 조회 / 예상대출금액 조회 / 대출 진행조회 / 간편 서류제출 / 대출 계좌조회 / 가상계좌 상환 / 증명서 발급 / 신용회복

## 기획자 메모
- 카드 3장이 슬라이드로 도는데, 3번째 카드만 '최대+숫자'가 아니라 링크 2개라 개발자가 별도 카드로 만들고 있음
- "간편 서류제출"이 상단 메뉴와 퀵링크에 둘 다 있음
- 퀵링크는 화면 좁아지면 4개씩 2줄, 더 좁으면 2개씩으로 접힘 (규칙이 기획서에 없어 매번 재논의)
- 브랜드 파란색/글꼴 정확한 값이 기획서에 없어 개발자가 눈대중으로 맞추는 중
