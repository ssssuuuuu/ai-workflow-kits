# As-Is: 고객 관리 화면 기획서 (예시, 가상 데이터)

## 화면: 고객 검색

- 상단에 돋보기 아이콘 + 입력창. 평소엔 아이콘만 보이다가 클릭하면 입력창이 펼쳐짐
- 입력 중이면 입력창 오른쪽에 X 버튼이 나타나 지울 수 있음
- 검색 버튼은 따로 없고 타이핑하면 바로 결과가 바뀜(디자이너 코멘트: "느낌만 전달, 딜레이는 개발팀이 알아서")
- 결과가 없을 때 화면: 문구만 "검색 결과가 없습니다" (별도 디자인 없음)

## 화면: 고객 목록 (검색 결과)

- 카드 형태로 고객 1명당 1개 카드: 프로필 사진(원형) + 이름(굵게) + 최근 방문일(작은 회색 글씨) + 오른쪽 끝에 등급 뱃지
- 카드를 누르면 상세 화면으로 이동
- VIP 고객 카드는 테두리를 금색으로 강조 (일반 카드와 스타일시트가 다름)
- 로딩 중에는 회색 네모 3개만 깜빡이는 placeholder (구현은 각 개발자가 다르게 처리 중)

## 화면: 고객 상세

- 상단: 이름 + 등급 뱃지 (목록 카드와 같은 뱃지인데 크기가 다름)
- 아래 정보 영역: "이메일 / 값" "전화번호 / 값" "가입일 / 값" "누적 구매액 / 값" 형태로 줄줄이 나열
- 이메일, 전화번호 항목에만 오른쪽에 "변경" 링크가 있음. 가입일/누적 구매액에는 없음
- 항목 사이 구분선 있음/없음이 화면마다 다름 (초기 시안엔 있었는데 최근 시안엔 빠짐)
- 값이 없는 경우(예: 전화번호 미등록) 처리 방식이 기획서에 없어서 개발자가 "-"로 임의 처리 중

## 기획자 메모

- 카드/뱃지 크기가 목록과 상세에서 다르게 그려져 있는데 의도된 것인지 실수인지 불명확
- 정보 영역의 "변경" 가능 항목과 불가능 항목 기준이 기획서에 명시돼 있지 않음
